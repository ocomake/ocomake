나오늘 개인정보처리방침

개정·시행일: 2026년 11월 4일 · 운영자: ocomake (개인 개발자)

나오늘은 기록과 할일을 기기에 남기고, 모으고, 다시 찾도록 돕는 앱입니다. 기록·첨부파일·이음 AI 대화와 분석은 기본적으로 기기에서 저장·처리하며, 운영자가 사용자 기록을 수집·보관하는 별도 서버는 운영하지 않습니다. 다만 모델 다운로드, 링크 미리보기, 위치의 주소 변환, 외부 SDK, 사용자가 선택한 공유·내보내기에서는 아래와 같이 외부 서비스가 정보를 처리할 수 있습니다.

1. 처리하는 정보와 목적

  • 기록과 첨부: 사용자가 입력·선택·촬영하거나 다른 앱에서 공유해 온 한마디, 사진·동영상·음성 등 첨부파일, 위치 표시, 덧붙인 말과 책 분류를 기기에 저장해 보기·검색·정리에 사용합니다.
  • 할일과 돌아보기: 사용자가 입력한 할일 본문, 날짜·시각·반복·알림 설정, 완료 내역, 덧붙인 말, 하루·주간 돌아보기와 관련 초안을 저장·표시·정리에 사용합니다. 선택적으로 기기에 동기화된 외부 캘린더를 읽기 전용으로 조회할 수 있습니다. 원래 캘린더의 일정을 수정·삭제하거나 완료 처리하지 않습니다.
  • 선택적 외부 캘린더 조회: 사용자가 캘린더 읽기 권한을 허용하고 캘린더를 선택하면, 기기 캘린더의 이름·계정 표시 정보와 선택한 캘린더의 일정 제목·설명·장소·시작/종료 시각·종일 여부·반복 회차를 읽습니다. 오늘·이번 주·달력·검색·하루 돌아보기·이음의 일정 조회에 사용하며 나오늘 서버에 전송하지 않습니다. 별도 클라우드 로그인이나 새 동기화 계정을 만들지 않습니다. 원래 캘린더 계정과 동기화는 해당 제공자가 관리합니다.
  • 연결과 분석 결과: 사용자가 연결한 사람·장소·주제와 기록 간 관계, 관련 자료 후보, 검색 색인, OCR로 읽은 글자, 사진 분류 및 요약·추천 결과 등을 기기에서 처리해 검색·연결·책 정리와 작성 중 참고에 사용합니다. 이음 AI의 모델 추론도 기기에서 수행합니다.
  • 작성 초안과 대화: 작성·수정 중인 한마디와 할일, 현재 이음 AI 대화와 참고한 자료를 작업 이어가기와 답변 제공을 위해 기기에 보관합니다.
  • 오늘의 챙김: 앱이 챙긴 내용, 관련 기록·할일의 연결 정보와 확인 상태를 저장하여 나중에 다시 볼 수 있게 합니다. 오늘의 챙김과 기기 알림창에 표시하는 푸시는 별도이며, 푸시를 꺼도 챙김 내역이 남을 수 있습니다.
  • 사진·카메라와 음성 입력: 촬영·스캔·선택한 이미지를 기록에 붙이고 기기 내 OCR·이미지 분석에 사용합니다. 음성 입력을 시작하면 마이크를 사용해 Android의 기기 내 음성 인식을 요청합니다. 앱은 음성 인식을 위해 음성을 운영자 서버로 보내거나 네트워크 음성 인식으로 대체하지 않습니다. 사용자가 별도로 선택한 음성 첨부파일은 기록의 첨부로 보관될 수 있습니다.
  • 위치: 사용자가 위치 기능을 켜고 권한을 허용하면 대략적인 지역명을 기록에 붙입니다. 상세 위치 기능을 선택하고 정확한 위치 권한도 허용한 경우 상세 주소를 붙일 수 있습니다. 위치 표시에는 지역명 또는 주소 문자열을 저장하며, 위치 기능이 얻은 위도·경도를 기록의 위치 필드에 저장하거나 이동 경로를 계속 수집하지 않습니다. 주소 변환 과정의 외부 처리는 아래 3절을 참고해 주세요.
  • 설정과 문의: 화면·입력·알림·분석·보안 설정, 백업·복원 시각과 기기 내 진단 값을 기능 제공과 오류 확인에 사용합니다. 이메일로 문의하면 이메일 주소, 문의 내용과 사용자가 보낸 첨부자료를 답변과 후속 응대에 사용합니다.

2. 권한과 이용자의 선택

카메라·마이크·위치 등 필요한 권한은 관련 기능을 사용할 때 요청합니다. 권한과 위치·링크 미리보기·분석·푸시 등의 선택 기능은 앱 또는 기기 설정에서 변경할 수 있습니다. 권한을 허용하지 않아도 그 권한이 필요한 기능 외의 기본 기록 기능은 사용할 수 있습니다. 정확한 위치는 기본 기록에 필수인 권한이 아닙니다.

할일과 하루 돌아보기의 기기 알림은 앱이 기기에서 예약·표시합니다. 이음 답변 완료 알림은 선택적으로 사용할 수 있습니다. 종료된 한마디 알림 기능은 제공하지 않습니다. 알림 권한이나 표시 설정을 변경하는 것과 기록·할일·오늘의 챙김을 삭제하는 것은 별도입니다.

3. 외부 서비스와 정보 전송

  • Google ML Kit: 기기 내 글자 인식·이미지 분석·문서 스캔 등에 사용합니다. Google은 해당 SDK의 제공·진단·사용량 분석을 위해 기기·앱 정보, 기기 또는 설치 식별자, 성능 지표와 API 설정 정보 등을 처리할 수 있습니다. 사용 기능과 SDK에 따라 범위가 다르며, 자세한 내용은 ML Kit 데이터 공개 안내를 참고해 주세요.
  • AI 모델 다운로드: 선택한 모델 파일을 Hugging Face 및 연결된 파일 제공 서버에서 내려받습니다. 제공처는 IP 주소, 요청한 파일 URL 등 접속 정보를 처리할 수 있습니다. 이 다운로드를 위해 기록 본문·사진·대화 내용을 모델 제공처로 보내지 않으며, 내려받은 모델의 추론은 기기에서 수행합니다. 제공처의 처리 방식은 Hugging Face 개인정보처리방침 등을 따릅니다.
  • 링크 미리보기: 기능이 켜져 있으면 기록에 포함된 웹 주소의 미리보기와 이미지를 가져오기 위해 해당 웹사이트 및 이미지 제공 서버에 연결할 수 있습니다. 사이트 운영자는 IP 주소, 요청한 URL 등 일반적인 접속 정보를 확인할 수 있습니다. 링크를 직접 열면 선택한 브라우저나 대상 앱이 처리합니다.
  • 위치·주소 변환과 기기 서비스: 지역명이나 상세 주소를 구할 때 위도·경도가 Android의 위치·주소 변환 서비스에서 처리되며, 기기 제조사 또는 서비스 제공자의 서버로 전달될 수 있습니다. 기기 내 음성 인식 모델 준비 등에서도 제공자의 네트워크 기능이 사용될 수 있습니다. 해당 처리와 보관은 제공자의 정책과 기기 설정에 따릅니다.
  • 공유·내보내기와 다른 앱으로 열기: 사용자가 선택하면 해당 기록·사진·첨부 또는 암호화 백업 파일이 선택한 앱이나 저장 위치로 전달됩니다. 선택한 클라우드 저장소나 대상 앱이 사본을 보관할 수 있으며, 그 이후 처리는 해당 서비스 정책에 따릅니다.
  • 문의: 이메일 문의는 사용자가 선택한 이메일 서비스와 운영자의 이메일 서비스를 통해 전달·보관됩니다. 답변에 필요하지 않은 기록이나 민감한 내용은 문의에 포함하지 않아도 됩니다.

운영자는 사용자 기록을 광고 목적으로 판매하거나 별도 기록 서버에 수집하지 않습니다. 기기 내 AI 분석을 사용한다는 것이 앱의 모든 기능에 네트워크 통신이 없다는 뜻은 아닙니다.

4. 저장·보호와 보유 기간

기록 데이터베이스와 저장된 첨부파일은 기본적으로 기기에서 암호화합니다. 개발자 설정에서 보호 옵션을 끄거나 전환이 완료되지 않은 경우 보호 상태가 달라질 수 있으며 앱에서 현재 상태를 안내합니다. 설정 정보, 촬영·가져오기·복원·외부 열기 등의 처리 과정에 쓰이는 임시 파일이나 사용자가 외부에 내보낸 사본까지 모두 같은 방식으로 암호화되는 것은 아닙니다. 처리 중 임시 파일은 정리 대상이지만 중단이나 오류로 남아 재정리가 필요할 수 있습니다.

  • 저장한 기록·할일·분류·연결: 사용자가 삭제하거나 앱 데이터를 지울 때까지 기기에 보관합니다. 완료·마무리한 기록도 다시 보기 위해 남을 수 있습니다.
  • 초안과 대화: 작업 복원과 이어가기에 사용하며, 사용자의 저장·초안 비우기·대화 새로 시작 또는 삭제 등 해당 기능의 처리에 따라 교체·정리됩니다. 일반 기록의 삭제와 별도로 보관될 수 있습니다.
  • 오늘의 챙김: 확인한 후에도 사용자가 지우기 전까지 남습니다. 읽음 처리는 할일 완료나 기록 삭제와 다릅니다.
  • 색인·분석 결과와 임시 자료: 기록의 검색·분석 및 화면 표시를 위해 보관하고 원문 변경·삭제와 기능별 정리 과정에서 갱신·정리합니다. 첨부 정리에 실패하면 정리 대기 상태를 남겨 다음 실행이나 다시 확인 시 참조 여부를 확인하고 재시도할 수 있습니다.
  • 문의 이메일: 답변과 후속 응대에 필요한 기간 동안 이메일 서비스에 남을 수 있습니다. 삭제를 원하면 아래 문의처로 요청해 주세요.

기기 분실·고장에 대비하려면 별도의 백업이 필요합니다. 앱 삭제나 기기 설정의 앱 데이터 삭제 시 앱 내부 데이터는 운영체제 정책에 따라 제거되지만, 외부로 내보낸 백업·공유 사본·갤러리 복사본은 자동 삭제되지 않습니다.

5. 수동 백업과 복원 전 보관 사본

Android 자동 백업은 사용하지 않습니다. 수동 백업은 사용자가 정한 비밀번호로 암호화해 선택한 위치에 내보냅니다. 백업 파일의 보관·전달·삭제와 비밀번호 관리는 사용자가 선택한 저장 위치에서 직접 관리해야 합니다.

  • 수동 백업에 포함되는 내용: 저장된 한마디·할일·돌아보기·덧붙인 말·책·연결·오늘의 챙김과 해당 첨부파일이 포함됩니다. 하루 마무리 초안도 포함될 수 있습니다.
  • 외부 일정의 보관: 선택한 캘린더 식별자는 기기 앱 설정에 보관합니다. 외부 일정은 조회할 때 읽으며 나오늘 할일이나 확정 하루 기록으로 자동 복제하지 않습니다. 조회 답변에 포함된 일정 내용은 암호화된 이음 대화에 남을 수 있고, 복원 전 보관 사본에도 당시 대화가 남을 수 있습니다. 연결을 끄거나 권한을 철회해도 과거 대화 문구가 자동 삭제되지는 않으며 해당 대화·사본에서 별도로 삭제할 수 있습니다. 원본 외부 일정은 원래 캘린더에서 관리합니다.
  • 수동 백업에 포함되지 않는 내용: 일반 작성·수정 중 한마디와 할일 초안, 현재 이음 AI 대화, 앱 설정, 기기의 외부 일정과 설치한 AI 모델은 포함하지 않습니다. 기록에 별도로 저장한 내용은 저장된 기록의 범위에 포함됩니다.
  • 복원으로 교체되는 내용: 복원하면 현재 기록과 첨부가 백업 내용으로 교체되며 작성 중인 글과 현재 대화도 초기화될 수 있습니다. 앱은 복원 전에 교체 범위와 주의 사항을 안내합니다.
  • 복원 전 원본의 별도 보관: 복원 과정에서 기존 데이터베이스·첨부·대화·초안·촬영 원본과 관련 보호 키 등을 앱 전용 내부 저장소의 복구 사본으로 보존할 수 있습니다. 이는 내보내는 수동 백업과 별개이며 현재 기록을 삭제해도 사본의 당시 내용은 남을 수 있습니다.
  • 사본의 보유·삭제: 복원이 검증 후 정상 완료되면 최근 정상 보관 사본 하나를 유지하도록 이전 정상 사본을 정리합니다. 오류·중단으로 격리한 사본은 복구를 위해 자동 삭제하지 않으며, 정리가 실패한 사본이 남을 수도 있습니다. 앱의 백업 화면에서 보관 상태를 확인하고 별도로 삭제할 수 있습니다. 사본 삭제는 현재 기록이나 외부 백업 파일을 삭제하는 작업과 다릅니다.

6. 이용자의 수정·삭제와 삭제 범위

  • 앱에서 기록·할일·대화·연결·오늘의 챙김 등을 기능별로 수정·삭제하고, 기기 설정에서 권한을 철회할 수 있습니다.
  • 책을 삭제하거나 책에서 기록을 빼는 동작은 원문 삭제와 다를 수 있습니다. 책 안의 한마디를 비울 때 다른 책에도 있는 원문은 해당 책의 소속만 해제하고, 보존 대상은 확인 화면에 안내합니다.
  • 원문을 삭제해도 별도로 남겨 둔 대화의 인용, 마무리한 날짜 기록, 오늘의 챙김, 복원 전 보관 사본, 내보낸 백업·공유본까지 함께 삭제되는 것은 아닙니다. 남아 있는 내용은 해당 화면이나 저장 위치에서 별도로 삭제해야 합니다.
  • 첨부파일을 다른 기록에서도 참조하거나 파일 정리에 실패한 경우에는 곧바로 모든 사본이 제거되지 않을 수 있습니다. 정리 실패는 앱에서 다시 확인하거나 재시도할 수 있습니다.
  • 앱 내부 데이터를 모두 지우려면 기기 설정에서 앱 데이터를 지우거나 앱을 삭제할 수 있습니다. 외부 저장소·갤러리·다른 앱의 사본은 각 위치에서 따로 삭제해 주세요.
  • 기록을 보관하는 운영자 서버가 없으므로 운영자는 기기 안의 기록을 원격으로 조회하거나 삭제할 수 없습니다. 문의 이메일 등 운영자에게 직접 전달한 정보의 삭제 요청은 아래 연락처로 보내 주세요.
