나오늘 개인정보처리방침

시행일: 2026년 10월 15일 · 운영자: ocomake (개인 개발자)

나오늘은 일상의 기록을 기기 안에 모으고 다시 찾아볼 수 있도록 돕는 앱입니다. 기록과 사진, 대화 내용은 기본적으로 기기에 저장·처리되며, 앱 운영자가 이를 보관하는 별도 서버는 운영하지 않습니다. 다만 아래에 설명한 외부 서비스 연결 시에는 관련 정보가 해당 서비스에 전달될 수 있습니다.

1. 처리하는 정보와 목적

  • 사용자가 남긴 기록: 한마디, 책 분류, 사진·동영상·첨부파일, 메모, 대화 내용 등을 기기에 저장하여 기록 보기·검색·분류·요약에 사용합니다.
  • 사진·카메라: 사용자가 선택하거나 촬영한 이미지를 기록에 붙이고, 기기 내 OCR·이미지 분석으로 검색과 분류에 활용합니다.
  • 음성: 사용자가 음성 입력을 시작할 때 마이크를 사용합니다. 앱은 기기 내 음성 인식을 요청하며, 녹음 파일을 앱 서버로 전송하지 않습니다.
  • 일정: 일정 접근을 허용한 경우 기기 일정의 내용을 읽어 연결·표시·검색에 사용합니다. 앱은 일정을 수정하지 않습니다.
  • 대략적인 위치: 위치 접근을 허용한 경우 기록에 지역 정보를 붙이기 위해 사용합니다. 정확한 좌표 자체는 기록에 저장하지 않습니다.
  • 문의: 사용자가 이메일로 문의하면 이메일 주소와 문의 내용을 답변에 사용합니다.

권한은 관련 기능을 사용할 때 요청하며, 기기 설정에서 철회할 수 있습니다. 허용하지 않아도 해당 기능 외의 기본 기록 기능은 사용할 수 있습니다.

2. 외부 서비스와 정보 전송

  • Google ML Kit: 기기 내 텍스트 인식 등에 사용합니다. Google은 모델 제공·업데이트와 서비스 운영 과정에서 기기·앱 정보 및 성능·사용량 정보를 수집할 수 있습니다. 자세한 내용은 ML Kit 데이터 공개 안내를 참고해 주세요.
  • AI 모델 다운로드: 필요한 모델 파일을 외부 호스팅에서 내려받을 수 있습니다. 모델 추론은 기기에서 이루어지며, 이 다운로드를 위해 기록 본문을 모델 제공처로 보내지 않습니다.
  • 링크 미리보기: 기록에 넣은 웹 주소의 미리보기를 가져올 때 해당 웹사이트에 연결됩니다. 사이트 운영자는 IP 주소와 요청한 URL 등 일반적인 접속 정보를 확인할 수 있습니다.
  • 기기 서비스: 지역명 변환이나 기기 내 음성 인식용 모델 준비 과정에서 Android 또는 기기 제조사·서비스 제공자의 네트워크 기능이 사용될 수 있으며, 처리 방식은 제공자의 정책에 따릅니다.
  • 공유·내보내기: 사용자가 공유, 백업 내보내기 또는 다른 앱으로 열기를 선택하면 선택한 내용이 대상 앱이나 저장 위치로 전달됩니다.

앱 운영자는 기록을 광고 목적으로 판매하거나 별도 서버에 수집하지 않습니다.

3. 저장, 보호 및 보유 기간

기록 데이터베이스와 첨부파일은 기본적으로 기기에서 암호화하여 저장합니다. 개발자 설정에서 관련 보호 옵션을 변경하면 보호 수준이 달라질 수 있습니다. Android 자동 백업은 사용하지 않습니다. 수동 백업은 비밀번호로 보호되며, 내보낸 파일의 보관과 삭제는 사용자가 선택한 저장 위치에서 직접 관리해야 합니다.

기록은 사용자가 앱에서 삭제하거나 앱 데이터를 지울 때까지 기기에 남습니다. 앱 삭제 시 기기 내 앱 데이터는 운영체제 정책에 따라 제거되지만, 내보낸 백업이나 다른 앱에 공유한 사본은 자동 삭제되지 않습니다. 문의 이메일은 답변과 후속 응대에 필요한 기간 동안 이메일 서비스에 남을 수 있으며, 삭제를 원하면 아래 연락처로 요청해 주세요.

4. 이용자의 선택과 삭제

앱 안에서 기록을 수정·삭제하고, 기기 설정에서 권한을 철회할 수 있습니다. 모든 앱 데이터를 삭제하려면 기기 설정에서 앱 데이터를 지우거나 앱을 삭제할 수 있습니다. 내보낸 백업과 공유한 사본은 각 저장 위치·서비스에서 별도로 삭제해야 합니다. 개인정보 관련 문의나 삭제 요청은 아래 이메일로 보내 주세요.
